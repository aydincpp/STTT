# Simple Terminal Typing Speed

A minimal terminal-based typing speed tester written in C.

## Description

This program reads words from a words.txt file (words separated by whitespace).

> **Note:** There are some small bugs and I’m very lazy to fix them. I may have created a better version of this in the future!

## Dependencies

- Linux (tested on Arch, kitty and xterm)
- `ncurses` library
- Nerd Fonts installed in your terminal

## Installation

1. Clone or download the source.
2. Ensure `ncurses` is installed.
3. Ensure you have a Nerd Font set in your terminal.

## Usage

```bash
make
./main
